# Hero Run asset credits

Hero Run: Time-Travel Adventure uses original, procedurally generated environment geometry and materials for its cinematic scenery.

## Stage 1–2 and Stage 3–5 scenery

- Mountain ridges, rolling hills, meadow backdrop, stream surface, water normal detail, foreground stones, grass blades, reeds, flowers, clouds and bird silhouettes are generated by the project code at runtime.
- These procedural assets were authored for Hero Run and do not reuse models, textures, characters, logos, or other assets from the visual reference.
- No third-party image, HDRI, texture, model, animation, or audio asset was added in these stages.
- Existing Hero Run character, enemy, boss, UI, and audio assets remain part of the project and retain their existing provenance.

## Third-party asset licensing

No new third-party assets were introduced by the cinematic scenery work covered by this file. If future stages add external CC0 or otherwise licensed content, record the source URL, creator, license, and any required attribution here before merging it.
